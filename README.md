# 나의 만세력

생년월일시로 사주팔자를 세우고, **대운·세운·월운·일진을 합산한 100점 운세**와 상담형 풀이를 보여주는 설치형 웹앱(PWA)입니다. 빌드 과정이 없는 정적 파일이라 GitHub Pages에 그대로 올리면 됩니다.

## 화면

| 탭 | 내용 |
|---|---|
| 오늘 | 일진, 종합 점수, 층별(대운·세운·월운·일진) 점수 구성, 분야별 점수 10가지, 하면 좋은 일·조심할 일 |
| 달력 | 분야를 골라 한 달 점수 보기. 이 달의 대운·세운·월운 점수 함께 표시 |
| 흐름 | 대운 10개, 세운 12년, 앞으로 24개월 월운 점수 그래프, 원국+운 오행 비율 |
| 풀이 | 원국표(지장간·12운성·신살·합충), 성향 → 강약·용신 → 직업 → 재물 → 연애 → 건강 → 대운 → 올해·내년 순서의 상담식 풀이 |
| 상담 | 질문을 고르면(창업 시기, 이직, 시험, 인연, 투자, 이사, 조심할 때) 앞으로 2년 중 맞는 달을 근거와 함께 답변 |

여러 사람을 저장할 수 있고, 정보는 그 기기의 브라우저(localStorage)에만 저장됩니다.

## 점수 체계

1. **원국 분석** — 천간 1, 지지는 자리 무게(월지 3, 일지 1.5, 나머지 1)를 지장간 비율로 나눠 오행을 셉니다. 나를 돕는 기운(비겁·인성) 비율로 극신약~극신강 5단계를 정하고, 억부로 용신을 고른 뒤 조후(한겨울·한여름 출생)를 보정합니다. 이 결과로 오행마다 -1~+1의 호불호 값이 정해집니다.
2. **층별 점수** — 대운·세운·월운·일진 기둥마다 따로 계산합니다.
   - 천간(45%)·지지 정기(55%)의 십신이 분야별 기본 점수를 줍니다. 예: 편재는 재물·이동, 정관은 일·문서.
   - 그 글자의 오행이 용신 쪽이면 좋은 분야를 키우고, 기신 쪽이면 조심할 분야를 키웁니다.
   - 원국 지지와의 충·합·형·원진, 일간과의 천간합·충, 천을귀인·문창·역마·도화를 더하고 뺍니다.
   - 바로 위 층과의 충(일진↔세운, 월운↔세운, 세운↔대운)도 반영합니다.
3. **합산** — 하루 점수 = 대운 20% + 세운 25% + 월운 25% + 일진 30%. 한 달은 대운·세운·월운, 한 해는 대운·세운만 씁니다.
4. **보정** — 원점수를 무작위 사주 500명 × 수만 개 날짜 분포의 백분위에 맞춰 0~100으로 바꿉니다(`js/calib.js`). 그래서 80점은 어느 해·어느 사람이든 "상위 약 7%"라는 같은 뜻입니다. 80점 이상(5단계)은 네 층이 모두 받쳐줄 때만 나옵니다.

| 점수 | 좋은 분야 | 조심할 분야 |
|---|---|---|
| 80+ | 최상 | 매우 주의 |
| 66~79 | 좋음 | 주의 |
| 50~65 | 보통 | 보통 |
| 35~49 | 약함 | 낮음 |
| 0~34 | 낮음 | 거의 없음 |

점수 규칙을 바꿨다면 보정표를 다시 만드세요.

```bash
node tools/calibrate.mjs > js/calib.js
```

## 파일 구조

```
index.html             화면 틀, 하단 탭
manifest.webmanifest   설치 정보(이름, 아이콘)
sw.js                  오프라인 캐시 — 파일을 바꾸면 VERSION을 올리세요
css/app.css
js/core.js             절기(태양 황경), 네 기둥, 대운, 월운 목록
js/analysis.js         오행 분포, 신강·신약, 용신, 격국, 신살, 합충
js/fortune.js          층별 점수, 합산, 보정
js/calib.js            보정표 (tools/calibrate.mjs로 생성)
js/reading.js          상담형 풀이 문장, 질문별 답변
js/app.js              화면 그리기, 사람 관리, 탭 이동
tools/calibrate.mjs    보정표 생성 스크립트 (Node 18+)
icons/                 앱 아이콘
```

## 배포 (GitHub Pages)

1. 새 저장소(예: `saju`)를 만들고 이 폴더의 파일을 모두 올립니다.
2. Settings → Pages → Branch를 `main`, 폴더를 `/ (root)`로 저장합니다.
3. `https://<아이디>.github.io/saju/`를 안드로이드 크롬에서 열고 메뉴 → **앱 설치(홈 화면에 추가)**를 누릅니다.

로컬에서 볼 때는 ES 모듈이라 파일을 직접 열면 안 되고 서버가 필요합니다.

```bash
python3 -m http.server 8000   # http://localhost:8000
```

## 계산 기준

- 절기는 태양 황경으로 계산하고(분 단위 오차), 태어난 시각은 출생지 경도(진태양시)와 1987·1988년 서머타임을 반영해 보정합니다.
- 하루의 경계는 자정, 한 달은 절기, 한 해는 입춘입니다.
- 대운수는 출생부터 절기까지 일수 ÷ 3(반올림), 만 나이 기준입니다.
- 음력 생일은 양력으로 바꿔서 넣어야 합니다.
- 해석은 전통 명리를 규칙으로 옮긴 참고용입니다.
